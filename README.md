# HelpLoop - Skill Exchange Platform

## Overview

HelpLoop is a skill exchange platform where users can share, learn, and exchange skills using a credit-based system. Users can create accounts, log in, add skills they can teach, and connect with others to exchange knowledge.

## Features

- User registration and login system
- Secure password hashing using bcrypt
- PostgreSQL database integration
- Session-based authentication
- User profile management
- Create and view skills
- Credit-based skill exchange system
- MVC project structure

## Technologies Used

### Backend
- Node.js
- Express.js
- PostgreSQL
- bcrypt
- express-session
- connect-pg-simple
- dotenv

### Frontend
